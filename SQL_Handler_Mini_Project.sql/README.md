# SQL Brand Information Procedure

## Description

This project demonstrates a MySQL Stored Procedure that generates brand statistics.

## Topics Covered

- Stored Procedure
- DECLARE
- SELECT INTO
- CONTINUE HANDLER FOR NOT FOUND
- INNER JOIN
- COUNT()
- AVG()

## Procedure

brand_information

## Features

- Find brand information
- Count products belonging to brand
- Calculate average product price
- Handle missing brand with NOT FOUND Handler
